# Sprout Tech

A React, TypeScript, and Vite site for the Sprout Tech digital studio.

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## GitHub Pages

Pushing to `main` builds and deploys the site to
https://asuwathkumaresh07-cyber.github.io/sprout_tech/.

## Deploy to Render

This repository also includes a `render.yaml` Blueprint for a Render Static
Site. In Render, choose **New → Blueprint**, connect this GitHub repository,
and deploy the detected Blueprint.
